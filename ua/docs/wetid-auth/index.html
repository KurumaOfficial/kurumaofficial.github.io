Автентифікація через WetID (Unified SSO & OAuth 2.0)

Останнє оновлення: 1 серпня 2026 р.
⚠️ Увага! Обмежений доступ до серверів WetID:
Сервери єдиної системи автентифікації WetID тимчасово перебувають у режимі обмеженого доступу. Повноцінна можливість реєстрації та входу буде відкрита в найближчому релизі.

Єдина система автентифікації WetID пов'язує акаунт користувача, придбані ліцензії (Strange Visuals, Aleph Trust) та статус апаратного довіри (Trust Level / Passkeys).

1. Архітектура протоколу OAuth 2.0

WetID працює за стандартом OAuth 2.0 (RFC 6749) та OpenID Connect. Ігрові клієнти, вебсервіси та сервери Minecraft звертаються до єдиного центру для отримання UUID гравця та токенів сесії.

  • Authorization Endpoint: https://wetid.aleph.icu/oauth/authorize
  • Token Endpoint: https://wetid.aleph.icu/oauth/token
  • Userinfo Endpoint: https://wetid.aleph.icu/api/v1/user/me

2. Параметри запиту автентифікації

Перенаправте користувача на форму входу за допомогою HTTP GET запиту:

GET /oauth/authorize?
  response_type=code&
  client_id=YOUR_CLIENT_ID&
  redirect_uri=https%3A%2F%2Fyourserver.com%2Fcallback&
  scope=openid+profile+email+trust_level&
  state=xyz_random_nonce HTTP/1.1
Host: wetid.aleph.icu

3. Обмін коду на Access Token

Надішліть отримати токен з вашого бекенду через HTTP POST:

POST /oauth/token HTTP/1.1
Host: wetid.aleph.icu
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
&client_id=YOUR_CLIENT_ID
&client_secret=YOUR_CLIENT_SECRET
&code=AUTH_CODE_RECEIVED
&redirect_uri=https%3A%2F%2Fyourserver.com%2Fcallback
