Проверка целостности модов (Modset Hash)

Последнее обновление: 1 августа 2026 г.

Система Aleph Trust проверяет каждый подгружаемый `.jar` файл в папке модов клиента для исключения чит-модификаций и инъекций стороннего кода.

1. Алгоритм вычисления Modset Hash

При запуске AMCLauncher строит криптографическое дерево Merkle Tree по содержимому всех `.jar` файлов и генерирует итоговый хэш SHA-256:

SHA256(Mod_1.jar + Mod_2.jar + ... + Mod_N.jar) = modset_hash

2. Разрешенные источники модов (Allowlist)

Моды должны быть скачаны из доверенных репозиториев (Modrinth / CurseForge) или подписаны цифровой подписью администратора сервера на тарифах Gimel и Dalet.
