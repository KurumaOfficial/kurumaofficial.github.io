API-документация Aleph Trust (REST API v1)

Последнее обновление: 1 августа 2026 г.

Справочник REST API для взаимодействия серверов Minecraft (Paper, Purpur, Velocity) с SaaS-системой допуска Aleph Trust.

1. Базовый URL и Авторизация Запросов

Все API-запросы должны отправляться по протоколу HTTPS на адрес https://api.aleph.icu/v1/trust.

Для авторизации сервера передавайте секретный ключ в заголовке X-Aleph-Server-Token:

X-Aleph-Server-Token: at_sec_99182a3b4c5d6e7f8

2. Проверка сессии входа (Session Verification)

Вызывается при попытке подключения игрока к серверу для проверки целостности клиента и уровня доверия.

POST /v1/trust/verify HTTP/1.1
Host: api.aleph.icu
Content-Type: application/json
X-Aleph-Server-Token: at_sec_99182a3b4c5d6e7f8

{{
  "username": "FrostCraft_Admin",
  "uuid": "069a79f7-b59f-474d-b3d6-d6284b39f418",
  "client_ip": "198.51.100.42",
  "launcher_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "modset_hash": "7f83b1657ff1fc53b92dc18148a1d65dfc2d4b1fa3d677284addd200126d9069",
  "hwid_token": "hw_tok_88192a3b"
}}

Успешный ответ (Допуск разрешен):

{{
  "status": "ALLOWED",
  "trust_level": "GIMEL_STRICT",
  "risk_score": 0.01,
  "session_id": "tsess_771829031",
  "features_enabled": ["CUSTOM_MODSET", "PASSTHROUGH_FORWARDING"],
  "message": "Verified official AMCLauncher client"
}}

3. Отзыв сессии (Session Revocation)

Позволяет принудительно кикнуть игрока и отменить сессию допуска при обнаружении нарушений:

POST /v1/sessions/revoke HTTP/1.1
Host: api.aleph.icu
Content-Type: application/json

{{
  "session_id": "tsess_771829031",
  "reason": "MODSET_HASH_MUTATION"
}}
