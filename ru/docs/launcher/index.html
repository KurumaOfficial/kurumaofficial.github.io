Решение проблем с AMCLauncher

Последнее обновление: 1 августа 2026 г.

Официальный лаунчер AMCLauncher обеспечивает безопасный вход на сервера с поддержкой защиты Aleph Trust и автоматической проверкой целостности клиента.

1. Системные требования и Java Runtime

  • Операционная система: Windows 10/11 (64-bit), Linux (x86_64), macOS 12+ (Apple Silicon / Intel).
  • Версия Java: Java 17 или Java 21 (Рекомендуется дистрибутив Eclipse Temurin или GraalVM).
  • Оперативная память (ОЗУ): Минимум 4 ГБ доступной оперативной памяти для сборки с модами.

2. Рекомендуемые аргументы JVM

Для предотвращения подвисаний (Garbage Collection freezes) используйте следующий набор флагов в настройках лаунчера:

-Xms4G -Xmx8G -XX:+UseG1GC -XX:+UnlockExperimentalVMOptions -XX:G1NewSizePercent=20 -XX:G1ReservePercent=15 -XX:MaxGCPauseMillis=50

3. Устранение ошибок запуска

Ошибка "Exit Code: 1" / Crash при старте:

Очистите папку .amclauncher/runtime и убедитесь, что драйвер видеокарты обновлен до последней версии.

Ошибка "ERR_ANTI_CHEAT_DRIVER":

Возникает при конфликте с античит-системами сторонних игр (Vanguard, Easy Anti-Cheat). Перезагрузите ПК и добавьте `amclauncher.exe` в исключения Брандмауэра Windows.
