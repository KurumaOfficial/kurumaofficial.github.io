Авторизация через WetID (Unified SSO & OAuth 2.0)

Последнее обновление: 1 августа 2026 г.
⚠️ Внимание! Ограниченный доступ к серверам WetID:
Серверы единой системы авторизации WetID временно находятся в режиме ограниченного доступа. Полноценная возможность регистрации и входа будет открыта в ближайшем релизе.

Единая система авторизации WetID связывает личный аккаунт пользователя, приобретенные лицензии продуктов (Strange Visuals, Aleph Trust) и статус аппаратного доверия (Trust Level / Passkeys).

1. Архитектура протокола OAuth 2.0

WetID работает по стандарту OAuth 2.0 (RFC 6749) и OpenID Connect. Игровые клиенты, веб-приложения и серверы Minecraft подключаются к единой точке входа для безопасного получения идентификатора игрока (UUID) и токенов сессии.

  • Authorization Endpoint: https://wetid.aleph.icu/oauth/authorize
  • Token Endpoint: https://wetid.aleph.icu/oauth/token
  • Userinfo Endpoint: https://wetid.aleph.icu/api/v1/user/me

2. Параметры запроса авторизации

Для перенаправления пользователя на форму входа сформируйте следующий HTTP GET запрос:

GET /oauth/authorize?
  response_type=code&
  client_id=YOUR_CLIENT_ID&
  redirect_uri=https%3A%2F%2Fyourserver.com%2Fcallback&
  scope=openid+profile+email+trust_level&
  state=xyz_random_nonce HTTP/1.1
Host: wetid.aleph.icu

3. Обмен кода на Access Token (Backend Exchange)

После подтверждения входа перенаправьте полученный code на Token Endpoint с бэкенда вашей системы:

POST /oauth/token HTTP/1.1
Host: wetid.aleph.icu
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
&client_id=YOUR_CLIENT_ID
&client_secret=YOUR_CLIENT_SECRET
&code=AUTH_CODE_RECEIVED
&redirect_uri=https%3A%2F%2Fyourserver.com%2Fcallback

Успешный ответ сервера (200 OK):

{{
  "access_token": "wt_at_99218204812a3b4c",
  "token_type": "Bearer",
  "expires_in": 86400,
  "refresh_token": "wt_rt_77182930411a2b",
  "scope": "openid profile email trust_level",
  "trust_level": "VERIFIED_DOC"
}}

4. Защита от перехвата (Intermittent Re-Authentication)

В систему WetID интегрирован модуль Intermittent Re-Authentication, защищающий аккаунт от физического захвата устройства и RAT-троянов. При вызове чувствительных методов API сервер может вернуть ответ 403 Forbidden с заголовком X-WetID-ReAuth-Required: true, требующим ввода 6-значного мастер-кода пользователя.
