User Agreement (EULA)

Updated: August 4, 2026

We build security tools (WetID, Aleph Trust, AMCLauncher, Strange Visuals). User privacy is a core architectural principle at Aleph Studio (WeTTeA). We process only the essential minimum of information required for authentication and cheat protection.

1. Processed Information

  • WetID SSO Account: Email, secure cryptographic password hash (Argon2id), username, and 2FA authentication state.
  • Hardware HWID Token: Anonymized hardware footprint (CPU, motherboard, GPU). Used strictly to prevent banned offenders from re-entering protected servers. Contains no personal information.
  • Technical Metrics: Masked IP address, Aleph Trust session verification tokens, and client headers.

2. How Data Is Used

  1. Single Sign-On (SSO) via WetID across all ecosystem products.
  2. Digital signature validation for Strange Visuals mods against unauthorized cheat injections.
  3. Validating Aleph Trust subscriptions (Beth, Gimel, Dalet plans) and issuing access tokens.
  4. Protecting infrastructure against DDoS attacks and ban evasion.

3. Security & Retention

All data is encrypted via AES-256 at rest and TLS 1.3 in transit. Temporary session logs are automatically purged every 30 days. Security audit logs are retained for 90 days.

4. Your Rights

You can request a full data export or complete account deletion ("Right to be Forgotten") at any time by contacting privacy@aleph.icu. Accounts and associated tokens are destroyed permanently.
